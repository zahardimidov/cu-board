# cu-board 🏆

Рейтинг успеваемости ЦУ среди друзей: общий лидерборд, рейтинг по каждому курсу, сданные ДЗ и late days.

```
🥇  Аня С.      ███████████████████░░░░░   80.0%  курсов: 7  3 ч назад
🥈  Захарий Д.  ███████████████░░░░░░░░░   65.2%  курсов: 7  только что  ← ты
🥉  Миша К.     ███████████████░░░░░░░░░   64.5%  курсов: 6  вчера
```

## ⚠️ Прежде чем запускать

**Твои оценки попадут в общую таблицу и будут видны всем участникам.** Туда попадают:
- имя в виде «Имя Ф.»;
- процент успеваемости и балл по каждому курсу, тип курса (основной или факультатив);
- сколько ДЗ сдано;
- остаток late days;
- время последнего запуска.

Пароль от аккаунта ЦУ утилита не видит и никуда не отправляет. Вход происходит на сайте ЦУ, в окне браузера.

Чтобы убрать себя из рейтинга, выполни `cu-board leave`.

## Как запустить

**1. Скачай файл для своей системы** с [Яндекс Диска](https://disk.yandex.ru/d/jLnWd1KFGUMzgA). Папка под паролем, пароль спроси у автора.

| Система | Файл |
|---|---|
| Mac на M1/M2/M3/M4 | `cu-board-mac-arm` |
| Mac на Intel | `cu-board-mac-intel` |
| Windows | `cu-board.exe` |

Какой у тебя Mac, видно в меню  → «Об этом Mac»: там написано Apple M… или Intel.

**2. Запусти.**

На **Mac** открой Терминал и выполни команды. Первые две нужны только один раз:
```sh
cd ~/Downloads
chmod +x cu-board-mac-arm
xattr -d com.apple.quarantine cu-board-mac-arm
./cu-board-mac-arm
```
Если у тебя Intel, замени `cu-board-mac-arm` на `cu-board-mac-intel`.

На **Windows** дважды кликни `cu-board.exe`. Если появится «Windows защитила компьютер», нажми «Подробнее» → «Выполнить в любом случае».

**3. Войди в аккаунт ЦУ** в открывшемся окне браузера. Окно закроется само, и откроется борд.

Нужен Chrome или другой браузер на Chromium: Edge, Яндекс Браузер, Brave, Arc. Safari и Firefox не подходят.
Браузер запускается с отдельным профилем, поэтому в первый раз войти придётся, даже если ты уже залогинен в обычном браузере.

**4. Запускай снова, когда хочешь обновить свои оценки.** Борд обновляется, только когда кто-то сам запускает утилиту.
Рядом с каждым человеком видно, когда он делал это в последний раз.

### Управление

| Клавиша | Действие |
|---|---|
| `←` `→`, `1`–`5` | вкладки: Общий · Курсы · ДЗ · Late days · Профиль |
| `↑` `↓`, `Enter` | выбрать и открыть курс |
| `Esc` | назад к списку курсов |
| `f` | учитывать факультативы в общем рейтинге и ДЗ |
| `q` | выход |

### Команды

```
cu-board          обновить свои оценки и открыть борд
cu-board explain  показать, как посчитаны твои проценты
cu-board login    войти заново
cu-board leave    удалить свои данные из таблицы
cu-board version  версия
```

Если утилита пишет «версия устарела», скачай новую с [Яндекс Диска](https://disk.yandex.ru/d/jLnWd1KFGUMzgA).

## Как считается успеваемость

```
балл активности = среднее оценок (0..10) по уже оценённым заданиям
успеваемость    = Σ вес × балл / Σ весов активностей, где есть хоть одна оценка
```

- Несданное в срок считается как 0. Задания на проверке и ещё не выданные не учитываются.
- Бонусные активности только добавляют баллы и не входят в знаменатель.
- Курс без единой оценки в рейтинг не попадает.
- **Общий** рейтинг — это среднее по курсам. По умолчанию учитываются только основные курсы, `f` добавляет факультативы.
  Тип курса берётся из LMS для каждого студента отдельно: у одного курс может быть основным, у другого — факультативом.
- **ДЗ** — доля домашек, сданных не на 0, среди тех, где уже стоит оценка.

Если курс в LMS настроен не по его правилам, исправления задаются в `overrides` в [score.go](score.go).
Сейчас там МНО: ДЗ 20%, сумма баллов / min(выдано, 13).

Курсы, которые не нужно учитывать вообще (SOFT-курсы и т.п.), перечислены во вкладке `ignore` общей таблицы: часть названия или id курса, по одному в строке. Они не загружаются при синке и скрыты из всех рейтингов.

## Для разработчика

### Настройка Google-таблицы (один раз, бесплатно)

1. [console.cloud.google.com](https://console.cloud.google.com) → создать проект → **APIs & Services → Enable APIs** → включить **Google Sheets API**.
2. **IAM & Admin → Service Accounts → Create** → открыть аккаунт → **Keys → Add key → JSON**. Положить файл в `secrets/credentials.json`.
3. Создать Google-таблицу и выдать email сервисного аккаунта доступ **Редактор**.
4. Записать id таблицы (часть URL между `/d/` и `/edit`) в `secrets/sheet_id`.

Вкладки `data`, `students` и `meta` утилита создаст сама. Без настроенной таблицы данные пишутся в `~/.cu-board/db.json`.
Ключ и id можно передать и через переменные `CU_BOARD_CREDENTIALS` и `CU_BOARD_SHEET_ID`.

### Сборка для друзей

Код в репозитории публичный, но **ключа таблицы в нём нет**. Бинарники с ключом собираются локально
и раздаются только своим:

```sh
echo "https://disk.yandex.ru/d/…" > secrets/download_url   # один раз: ссылка на папку на Диске
git tag v1.0.0                                              # версия берётся из тега
./build.sh                                                  # → dist/
```

Залей содержимое `dist/` в папку на Яндекс Диске и отправь ссылку друзьям.

> **Не выкладывай бинарники из `dist/` в GitHub Releases или куда-то ещё публично.** Ключ лежит внутри
> обычным текстом (`strings cu-board | grep "PRIVATE KEY"`), и любой скачавший сможет прочитать и стереть таблицу.
> Если файл всё же утёк, удали ключ в Cloud Console (**Service Accounts → Keys**), создай новый и пересобери.

Без `secrets/` проект тоже собирается, но такая сборка пишет данные в локальный файл `~/.cu-board/db.json`.

### Совместимость версий

`dataVersion` в [version.go](version.go) — номер формата данных и формулы. **Увеличивай его при любом изменении
колонок или расчёта процентов.** Новая версия записывает свой номер во вкладку `meta`. Старые бинарники видят там
номер больше своего, останавливаются до входа и любой записи и показывают ссылку из `secrets/download_url`.

### Локальная сборка

```sh
go build -o cu-board . && ./cu-board
```

Сессия и профиль браузера хранятся в `~/.cu-board/`.
